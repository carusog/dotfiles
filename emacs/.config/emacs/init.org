* The Performance "Hack"

By raising the Garbage Collection threshold, Emacs doesn't stop to clean up memory while it is trying to load my packages.

#+begin_src emacs-lisp :tangle ./early-init.el

  ;; Speed up startup by temporarily increasing garbage collector threshold
  (setq gc-cons-threshold most-positive-fixnum)

  ;; Lower it back to a reasonable level after startup
  (add-hook 'emacs-startup-hook
            (lambda ()
              (setq gc-cons-threshold (* 2 1024 1024))))

#+end_src

* Basic Behavior

Delete selection on typing (delsel) and improve =C-g= behavior.

#+begin_src emacs-lisp

  (use-package delsel
    :ensure nil
    :hook (after-init . delete-selection-mode))

  (defun prot/keyboard-quit-dwim ()
    "Do-What-I-Mean behavior for `keyboard-quit`."
    (interactive)
    (cond
     ((region-active-p)
      (keyboard-quit))
     ((derived-mode-p 'completion-list-mode)
      (delete-completion-window))
     ((> (minibuffer-depth) 0)
      (abort-recursive-edit))
     (t
      (keyboard-quit))))

  (define-key global-map (kbd "C-g") #'prot/keyboard-quit-dwim)

#+end_src

Basic Org mode setup.

The main /sources of inspiration/:

- [[https://www.howardism.org/Technical/Emacs/orgmode-wordprocessor.html][Org as a Word Processor]]
- [[https://zzamboni.org/post/beautifying-org-mode-in-emacs/][Beautifying Org Mode in Emacs]]

#+begin_src emacs-lisp

(use-package org
  ;; :hook
  ;; ((org-mode . variable-pitch-mode))

  :bind
  ("C-c a" . org-agenda)
  ("C-c c" . org-capture)
  ("C-c l" . org-store-link)

  :config
  ;; Basic Org settings
  (setq org-hide-leading-stars t
	org-hide-emphasis-markers t
	org-ellipsis " ⇥ "
        org-hide-block-startup t)

  ;; Remove the initial two-spaces indentation inside code block
  (setq org-edit-src-content-indentation 0)
  (setq org-todo-keywords '((sequence "TODO(t)" "WAIT(w)" "SDAY(s)" "PROJ(p)" "|" "DONE(d!)" "CANC(c)")))
)	    				     

;; Set Org-mode default folder

      org-agenda-file "~/Documents/org/")
